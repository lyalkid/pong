# Pong Game (Игра Понг)

Простая консольная игра Pong, реализованная на языке C, созданная во время отборочного интенсива в Школу 21.

## Описание игры

Это классическая игра Pong, в которой два игрока управляют ракетками, отбивая мяч. Особенности игры:
- Двухпользовательский режим
- Отслеживание счета
- Управление ракетками в реальном времени
- Физика мяча с обнаружением столкновений
- Терминальная графика

## Управление

### Игрок 1 (Левая ракетка):
- **A/a**: Движение ракетки вверх
- **Z/z**: Движение ракетки вниз

### Игрок 2 (Правая ракетка):
- **K/k**: Движение ракетки вверх
- **M/m**: Движение ракетки вниз

### Запуск мяча:
- **Пробел** или любая клавиша управления

## Правила игры
- Каждый игрок начинает с 20 очками
- Игрок теряет очко, когда пропускает мяч
- Игра до 21 очка
- Мяч отскакивает от стен и ракеток

## Компиляция и запуск

```bash
gcc pong.c -o pong
./pong
```

## Особенности разработки
- Создано самостоятельно в первую неделю отборочного интенсива Школы 21
- Разработано без использования ИИ
- Полностью ручная реализация всей логики
- Использованы ANSI escape коды для управления терминалом

## Техническая реализация
- Игровое поле: 80×25 символов
- Ракетки размером 3 символа
- Реализована физика отскоков
- Система подсчета очков
- Определение победителя
